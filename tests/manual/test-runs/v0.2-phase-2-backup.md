pg_restore exit still raises `RestoreError`).

## Findings

1. **macOS-default `openrsync` doesn't support `--info=stats2` or
   `--mkpath`.** The 2a draft used `--info=stats2`, which `openrsync`
   rejects with "unrecognized option". Fixed by dropping that option
   from the rsync command line. The `--mkpath` analog is emulated in
   Python: the backup code does `mkdir(parents=True, exist_ok=True)`
   on local destinations before calling rsync.
2. **`pg_restore --clean --if-exists` exits non-zero against a fresh
   DB** with a `warning: errors ignored on restore: N` line. The
   IF-EXISTS DROPs match zero rows but are still counted. Fixed by
   tolerating that specific shape in `compendium.backup.restore`.

Both fixes are landed in this branch alongside this evidence file.
