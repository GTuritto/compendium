# v0.4 Phase 0 — Clear the Deck: Implementation Plan

Date: 2026-06-12
Branch: `v0.4-phase-0-clear-the-deck` (off `main`)
OpenSpec change: `openspec/changes/v0.4-phase-0-clear-the-deck/`
Spec source: [docs/COMPENDIUM_V0.4_BUILD.md](../docs/COMPENDIUM_V0.4_BUILD.md) § 4 (Phase 0).

## Goal

Remove the three pieces of known noise before v0.4's real measurement starts:
the mutmut experiment gets its verdict (retired), the access-surface wire
format gets byte-frozen snapshot tests, and the ask cost table gets real
prices plus a loud warning for unknown models. Cheap, week-one, parallel with
Track A. None of this is the point of v0.4; all of it should be gone before
the harness work begins.

## Why this plan exists

Phase 0 looks too small to plan, which is exactly how scope leaks in. This
plan locks three boundaries: the mutants verdict is *retire*, not *adopt*
(adopting a mutation gate is its own project); the snapshot tests pin the
wire format without touching the serializer (zero behaviour change); and the
cost fix is a warning plus table entries, not a pricing subsystem (no network
lookups, no new dependency, schema unchanged).

## Verified ground (read before writing this plan)

- `mutants/` is 30M, local-only: `.gitignore:62` already carries `mutants/`,
  and `mutmut` appears nowhere in `pyproject.toml` or `uv.lock`. The verdict
  therefore produces no repo diff — it is a local delete plus closing draft
  PR #47 (`quality-mutation-testing`, open since 2026-06-05).
- The wire contract is `render.to_json` = `json.dumps(payload, indent=2,
  default=str)` (`compendium/cli/render.py:28-36`); `api/serialize.to_payload`
  round-trips through it (`compendium/api/serialize.py:25`). The existing
  `test_to_payload_matches_render_json` (`tests/test_facade.py:30`) proves
  path equivalence but freezes no bytes.
- The rate table (`compendium/answer/cost.py:11-17`) has five entries and a
  silent `(0.0, 0.0)` fallback at line 24. The model name priced is whatever
  `SYNTHESIS_MODEL` resolves to in `.env`.

## Sub-phases

### 0a — mutants verdict

**Purpose:** retire the mutmut experiment on record so it stops taxing every
future explorer.

**Tasks:**

1. `rm -rf mutants/` (local, untracked — no diff).
2. Close draft PR #47 with a comment citing
   `docs/COMPENDIUM_V0.4_BUILD.md` § 4 ("delete the tree... adopting a
   mutation gate is its own project and not this quarter's"); delete the
   `quality-mutation-testing` remote branch.
3. CHANGELOG line under Unreleased recording the verdict.

**Files added:** none. **Files modified:** `CHANGELOG.md`.

**Decision flagged:** retire, not adopt. The skip-not-fail live tier argument
for a mutation gate is real; it loses on cost this quarter and is recorded in
the spec so review #6 does not re-suggest it.

### 0b — wire-format snapshot tests

**Purpose:** make any wire-format change a deliberate test edit.

**Tasks:**

1. `tests/test_wire_format.py`: canned, fully-populated instances per facade
   verb payload shape — `RetrievalResult` (query), the ask result envelope,
   the ingest result, page payloads (`page_get`/`page_list`), and the index
   status shape — built inline with fixed UUIDs/timestamps (strings via
   `default=str` are part of the frozen contract).
2. One test per verb: `render.to_json(obj)` equals a frozen literal,
   assertion message naming the contract ("wire format for HTTP / MCP /
   --format json callers — changing this is an API change").
3. The `to_payload` equivalence cross-check over the same canned inputs.

**Files added:** `tests/test_wire_format.py`. **Files modified:** none.

**Decision flagged:** snapshots live against `render.to_json` (the seam both
the CLI and `to_payload` share), not against HTTP responses — no server, no
stores, hermetic.

### 0c — cost table completion

**Purpose:** real money flows through ask in v0.4; a silent 0.0 undercounts
every call.

**Tasks:**

1. Update `_RATES` with current prices for the models actually run (confirm
   the `SYNTHESIS_MODEL` value(s) in use; keep existing entries, correct any
   stale rates).
2. In `estimate_cost`, log `structlog` warning `unknown_model_rate` (with the
   model name) when the model is not in `_RATES` and is not the stub; return
   0.0 unchanged.
3. Tests: unknown model logs the warning and records 0.0; known model logs
   nothing; stub stays silent.

**Files added:** none. **Files modified:** `compendium/answer/cost.py`,
`tests/test_ask.py`.

**Decision flagged:** warning + 0.0, not a sentinel value — the
`ask_traces.cost_estimate` schema and every consumer stay untouched.

### 0d — docs and close

**Purpose:** thread the phase through the living docs and cut the version.

**Tasks:**

1. CHANGELOG entries for 0b/0c; smoke section appended to
   `tests/manual/smoke_test.md`.
2. Full fast tier + golden green (`uv run pytest`).
3. `./release.sh 0.3.1` in the completion commit.

**Files modified:** `CHANGELOG.md`, `tests/manual/smoke_test.md`, `VERSION`,
`pyproject.toml`, `uv.lock`, `2Deploy/` (release script output).
