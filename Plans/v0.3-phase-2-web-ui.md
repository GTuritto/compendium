# Phase Plan — v0.3 Phase 2: Web UI (Streamlit, loopback)

Plan of record: [docs/COMPENDIUM_V0.3_BUILD.md](../docs/COMPENDIUM_V0.3_BUILD.md) Phase 2
· OpenSpec: `openspec/changes/v0.3-phase-2-web-ui/` · Branch: `v0.3-phase-2-web-ui`
· Ships **ADR-015** · Version on completion: **0.2.5** (then `0.3.0` on plan completion)

## Goal (verbatim)

A browser surface for the daily read / ask / curate loop, on `127.0.0.1`,
reusing the existing facade and TUI data paths — no new retrieval or answer
logic, no network exposure.

## Open questions resolved

- **Q3 — curation seam:** `tui/data.py` already *is* the shared channel-free
  provider (pure functions over `curate/` + Phase 1's `resolve_signal`); the
  web UI imports it as-is. Nothing to extract.
- **Q4 — launch:** the `compendium web` subcommand (consistent with
  `serve`/`mcp`/`tui`); it execs `streamlit run` on the packaged app with
  `--server.address`/`--server.port` and headless flags; the loopback default
  lives in one place.
- **Q5 — service unit:** none in v0.3; the web UI is interactive,
  manual-launch. Revisit with the v0.4 exposure decision.

## Sub-phases

- **2a — the app + verb:** `streamlit` in `pyproject.toml` (ADR-015's one new
  dependency); `compendium/web/app.py` (sidebar-routed Ask / Search / Pages /
  Curation, every action over `facade.*` or `tui/data.py`; refusals render
  the gap + suggested actions; contradiction candidates get Approve / Drop,
  coverage signals get Synth); `compendium/web/__init__.py` launcher
  (`run(host, port)` building the streamlit argv); the `web` subcommand.
- **2b — tests:** launcher argv unit test (fake exec); Streamlit `AppTest`
  smokes per view against a monkeypatched facade/provider (hermetic, no
  stores).
- **2c — docs:** ADR-015 inline (stack-discipline exception rationale +
  loopback restraint + v0.4 path); `docs/operations/web-ui.md`; MANUAL Part 2
  + command reference; CONTEXT.md glossary (*Web UI*); CLAUDE.md posture
  lines gain the pointer; DECISIONS + CHANGELOG; smoke section v0.3-2.x.
- **2d — completion:** `./release.sh 0.2.5` in the completion commit. After
  merge: the v0.3 close-out on `main` (C4 refresh folding in the web-UI
  container + contradiction flow, `0.3.0` cut + tag).

## Smoke test

`compendium web`; ask a covered question (answer + citations) and an
uncovered one (refusal + suggested actions); search and open a page; in
Curation, approve a `contradiction_candidate` and confirm the edge in
`compendium graph status`; confirm the bind is loopback-only.

## Acceptance gates

Full fast + golden + `ci-smoke.sh` green; AppTest smokes green; no new
retrieval/answer/curation logic (the app imports facade + tui/data only);
pipeline green on merge.
