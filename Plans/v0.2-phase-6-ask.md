# v0.2 Phase 6 — Composed answers (`ask`): Implementation Plan

Date: 2026-05-31
Branch: `v0.2-phase-6-ask` (off `main`)
OpenSpec change: `openspec/changes/v0.2-phase-6-ask/`
Spec source: [docs/COMPENDIUM_V0.2_BUILD.md](../docs/COMPENDIUM_V0.2_BUILD.md) § Phase 6;
[docs/Compendium.md](../docs/Compendium.md) ADR-011 (`ask` is one of the six access-surface
verbs); the v0.2 thesis ("better answers").

## Goal

The `ask` CLI command returns an LLM-composed answer over the top-K pages, with
structured citations, a refusal mode, and its own trace row.

## Why this plan exists

v0.1 deliberately stopped at ranked pages: `compendium query` returns pages with chunk
citations and the curator reads them. The v0.1 exclusion line was "Not a chat UI and not
LLM-composed answers." v0.2's thesis is "better answers", and the build plan reverses that one
line for a single new verb: `ask`. This plan locks the shape of that verb so it composes *on
top of* the page-first substrate without forking the retrieval contract.

Phase 6 also lands "Shape D part 2" — the LLM query rewrite that Phase 5 kept off the cost-free
`query` hot path. Rewrite belongs to `ask` (which already pays for an LLM call); `query` stays
LLM-free.

Three concrete deliverables:

1. **A composer that refuses.** Below `ask.refuse_below_coverage` (default `0.3`) `ask`
   returns `answer=null`, `refused=true`, a populated `gap`, and `suggested_actions` naming
   the next CLI command — without making a composition LLM call. Refusal protects the
   "answers grounded in the wiki" contract from hallucinating over thin coverage.
2. **An `ask_traces` companion row.** Every `ask` writes an `ask_traces` row joined to the
   `query_traces` row by `query_trace_id`, recording the prompt template id, model + endpoint,
   token counts, a cost estimate, and the answer text. Tracing stays non-optional.
3. **Structured, page-anchored citations.** The response is a structured `AskResult`, not free
   prose; citations carry `trace_rank` so the curator can audit which page produced which
   claim.

The plan locks these decisions (each also recorded in the OpenSpec `design.md`):

1. **The composer lives in a new `compendium/answer/` package**, mirroring
   `compendium/retrieve/`'s multi-module layout. `answer.ask()` is the public function; the
   package name avoids an `ask.ask` collision and reads well for Phase 7's facade.
2. **`ask` reuses `pipeline.query`** — it does not re-retrieve. The answer is grounded in
   exactly the pages a plain `query` would return; the two traces tell one story.
3. **Refusal is a hard coverage gate computed before any composition call.** Cheaper,
   deterministic, and not subject to the model answering anyway.
4. **The LLM rewrite is `ask`-only and runs before retrieval**, gated by `ask.rewrite`
   (default `true`). `query` never rewrites.
5. **`ask_traces` is a new table referencing `query_traces`** (migration `0012`,
   `down_revision = "0011"`), not nullable columns bolted onto `query_traces`.
6. **Cost estimate** = `tokens * static per-model rate`, with a `0.0` fallback for unknown
   models and the stub. Informational, not billing-grade.
7. **Streaming for `--format text`; buffering for `--format json`.**

## Sub-phases

### 6a — `ask_traces` schema + repository

**Purpose:** persist the composition-specific trace data joined to the existing query trace.

**Tasks:**

1. `migrations/versions/0012_ask_traces.py`: `CREATE TABLE ask_traces` with `id UUID PK`,
   `query_trace_id UUID REFERENCES query_traces(id)`, `prompt_template_id TEXT NOT NULL`,
   `model TEXT NOT NULL`, `endpoint TEXT NOT NULL`, `input_tokens INT`, `output_tokens INT`,
   `cost_estimate DOUBLE PRECISION`, `answer_text TEXT`, `refused BOOLEAN NOT NULL DEFAULT
   FALSE`, `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`; index on `(query_trace_id)`.
   `down_revision = "0011"`; `downgrade()` drops the table.
2. `compendium/db/repository.py`: `insert_ask_trace(...)` mirroring `insert_query_trace`;
   `get_ask_trace(conn, ask_trace_id)`; a join helper returning the ask trace alongside its
   query trace.
3. Migration round-trip test (upgrade + downgrade `0012`).
4. Repository round-trip test (`insert_ask_trace` → `get_ask_trace`, link intact).

**Files added:** `migrations/versions/0012_ask_traces.py`
**Files modified:** `compendium/db/repository.py`, `tests/test_db.py` (or the migration test
module)

**Decision flagged:** companion table, not columns on `query_traces` — a plain `compendium
query` produces a query trace with no ask trace; the FK keeps the relation explicit.

### 6b — The `ask` composer

**Purpose:** the rewrite → query → compose flow with refusal, citations, and the trace write.

**Tasks:**

1. `compendium/answer/__init__.py`: re-export `ask`, `AskResult`.
2. `compendium/answer/compose.py`: `@dataclass AskResult` (`answer`, `refused`, `citations`,
   `coverage_score`, `trace_id`, `ask_trace_id`, `gap`, `suggested_actions`) and `@dataclass
   Citation` (`ref`, `slug`, `title`, `trace_rank`).
3. `compendium/answer/compose.py`: `ask(question, *, stream=False) -> AskResult` — optional
   rewrite → `pipeline.query` → read `coverage_score` → refusal branch (no composition call)
   below threshold, else compose over the top-K pages → attach citations from the final
   ranking → write `ask_traces` → return.
4. `compendium/answer/rewrite.py`: `rewrite_query(question, synthesizer) -> str`, gated by
   `ask.rewrite`; passthrough when disabled.
5. `compendium/answer/prompts.py`: the compose template (`ask-v1`) and the rewrite template.
6. `compendium/answer/cost.py`: a static per-model rate table + `estimate_cost(...)` with a
   `0.0` fallback.
7. `suggested_actions` rule: zero covering pages → an `ingest` suggestion; thin coverage with
   pages present → a `synth concept "<top title>"` suggestion.
8. Unit tests with the stub synthesizer (covered → answer + citations; uncovered → refusal +
   suggested actions + no composition call; rewrite transforms + recorded; `rewrite=false`
   passthrough).

**Files added:** `compendium/answer/__init__.py`, `compendium/answer/compose.py`,
`compendium/answer/rewrite.py`, `compendium/answer/prompts.py`, `compendium/answer/cost.py`,
`tests/test_answer.py`
**Files modified:** `compendium/wiki/synth.py` (a streaming sibling on the synthesis seam, if
needed for 6c streaming)

**Decision flagged:** `ask` calls `pipeline.query` rather than re-retrieving; one retrieval
contract, auditable citations.

### 6c — CLI verb + render + config

**Purpose:** expose `ask` as a CLI verb with the structured/streamed output and the config.

**Tasks:**

1. `config/settings.yaml`: an `ask:` block — `refuse_below_coverage: 0.3`,
   `prompt_template_id: ask-v1`, `rewrite: true`. LLM endpoint/model/key reuse `synthesis:`.
2. `compendium/config.py`: surface the `ask` config.
3. `compendium/__main__.py`: the `ask` subparser (`ask "<question>"`, `parents=[fmt]`) + an
   `_ask` handler (parse → call `compendium.answer.ask` → render → print; non-zero exit only
   on hard error, not refusal).
4. `compendium/cli/render.py`: an `ask(result, fmt)` renderer — text prints answer → citations
   → coverage/trace ids; refusal prints gap + suggested actions; json emits the full object.
5. Streaming: `--format text` streams the answer tokens; `--format json` buffers; refusal does
   not stream.
6. Integration test: end-to-end `ask` against a populated test DB with the stub synth (covered
   → answer + citations + joined `ask_traces`; uncovered → refusal + `ask_traces` with
   `refused=true`).

**Files modified:** `config/settings.yaml`, `compendium/config.py`,
`compendium/__main__.py`, `compendium/cli/render.py`, `tests/test_cli.py` (or the integration
test module)

**Decision flagged:** streaming is a `text`-mode affordance; the JSON contract stays one
object per invocation.

## Out of scope for Phase 6 (do NOT build)

- The MCP + HTTP access surface (Phase 7, ADR-011). `ask` is a callable + a CLI verb here;
  Phase 7's facade imports this composer.
- Multi-turn / conversational `ask`. Single question, single answer; no session state.
- Answer caching or memoization.
- A TUI screen for `ask`.
- Autonomous semantic-edge extraction (Phase 8, ADR-010).
- pgvector-backed `ask`-trace similarity.
- A pricing-API cost lookup (the static rate table is the v0.2 method).

## Open questions to confirm before starting

1. **Composer package name.** Recommendation: `compendium/answer/` with `answer.ask()`.
   Alternative: `compendium/ask/` with `ask.run()` (avoids `ask.ask`). The curator signs off.
2. **Rewrite default.** Recommendation: `ask.rewrite=true`. Alternative: off by default until
   the rewrite prompt is tuned (cost control).
3. **Refusal threshold.** Recommendation: `0.3` per the build plan. Confirm or adjust.
4. **Cost-estimate rate table.** Recommendation: a static per-model table in code with a `0.0`
   fallback. Confirm vs omitting cost entirely.
5. **`suggested_actions` shape.** Recommendation: a list of copy-paste-ready CLI command
   strings. Alternative: a structured `{verb, args}` shape that Phase 7's access surface might
   prefer to re-render.
