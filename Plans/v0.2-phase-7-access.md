# v0.2 Phase 7 — Access surface (MCP + HTTP): Implementation Plan

Date: 2026-05-31
Branch: `v0.2-phase-7-access` (off `main`)
OpenSpec change: `openspec/changes/v0.2-phase-7-access/`
Spec source: [docs/COMPENDIUM_V0.2_BUILD.md](../docs/COMPENDIUM_V0.2_BUILD.md) § Phase 7;
[docs/Compendium.md](../docs/Compendium.md) ADR-011 (the access surface) and ADR-012

## Goal

Compendium becomes callable from colocated agents via MCP (stdio) and from any local process
via HTTP REST/JSON — both over one shared facade, six verbs, localhost/stdio only, no auth.
**Ships ADR-011.**

## Why this plan exists

v0.1 was CLI + TUI only; external systems shelled out and parsed `--format json`. v0.2's
thesis admits "callable by colocated systems": the curator's coding agents (AgentTrader,
Ubongo) should use Compendium as long-term memory without spawning a CLI per call. ADR-011
fixes the shape — two transports, one facade, six verbs, no auth (the callers are colocated,
so there is no network to authenticate against). This plan locks that shape so the surface
stays small and cannot drift from the CLI.

Three deliverables:

1. **One shared facade** (`compendium/api/facade.py`) wrapping `pipeline.query`, `answer.ask`,
   `ingest`, and the repository readers, returning the dataclass shapes the render seam
   already serializes. Both transports are thin shells over it.
2. **Two transports.** `compendium serve` (FastAPI on `127.0.0.1`, no auth) and
   `compendium mcp` (official MCP SDK, stdio). `ask` streams over both.
3. **Agent-shaped `ingest`.** Accepts file paths *and* raw bytes (with a `filename` hint) and
   auto-runs `index sync` before returning — "I added it; query finds it". The CLI keeps its
   explicit two-step.

The plan locks these decisions (also in the OpenSpec `design.md`):

1. **One facade, two thin adapters.** Transports do transport only; the facade is the single
   home of the verb wiring and the auto-sync/raw-bytes `ingest` semantics.
2. **HTTP is FastAPI + uvicorn** (ADR-011 names FastAPI); **MCP is the official `mcp` SDK**
   over stdio. Both are new deps, argued for by ADR-011, lazily imported inside their handlers.
3. **One shared serializer.** The dataclass→dict step is factored so the access-surface JSON
   is byte-for-byte the `--format json` shape and the three surfaces (CLI, HTTP, MCP) cannot
   drift.
4. **Access-surface `ingest` auto-syncs**; the CLI does not. Raw bytes handled at the boundary
   (temp file), the `ingest` core unchanged.
5. **`ask` streams via the Phase 6 `on_token` callback** — HTTP wraps it in a chunked
   `StreamingResponse`; MCP uses progressive content. Both end with the structured result.
6. **Default bind `127.0.0.1:8787`** (collision-free against the dev store ports).

## Sub-phases

### 7a — The shared facade

**Purpose:** one home for the six verbs, returning the existing dataclass shapes; the only
place business logic is reached.

**Tasks:**

1. `compendium/api/__init__.py`: package init; re-export the verbs.
2. `compendium/db/repository.py`: `list_wiki_pages(conn, *, kind=None, status=None,
   limit=200) -> list[dict]` (id, kind, slug, title, status, file_path, created_at; newest
   first).
3. `compendium/api/facade.py`: `query(text) -> RetrievalResult`; `ask(question, *,
   on_token=None) -> AskResult`; `ingest(*, path=None, content=None, filename=None, kind,
   mine=False) -> IngestResult` (path or raw bytes → temp file → existing `ingest` →
   `sync_pending()` → cleanup); `page_get(kind, slug) -> dict | None` (frontmatter + body from
   the vault file); `page_list(*, kind=None, status=None, limit=200) -> list[dict]`;
   `index_status() -> IndexStatusReport`.
4. `compendium/api/serialize.py` (or a reused `render` helper): the single dataclass→dict step
   both transports call, matching `--format json`.
5. Facade unit/integration tests: each verb's shape; raw-bytes `ingest` writes + ingests +
   syncs + cleans up; `page_get` miss → `None`.

**Files added:** `compendium/api/__init__.py`, `compendium/api/facade.py`,
`compendium/api/serialize.py`, `tests/test_facade.py`
**Files modified:** `compendium/db/repository.py`

**Decision flagged:** the facade returns dataclasses; serialization is shared so the contract
lives once. Access-surface `ingest` auto-syncs (CLI does not).

### 7b — HTTP transport (`compendium serve`)

**Purpose:** REST/JSON over the facade on `127.0.0.1`, no auth, with `ask` streaming.

**Tasks:**

1. `compendium/api/http.py`: a FastAPI app — `query`/`ask` POST JSON; `page_get`/`page_list`/
   `index_status` GET; `ingest` POST (JSON path, or bytes via base64/multipart + `filename` +
   `kind`). Responses use the shared serializer.
2. `ask` streams over a chunked `StreamingResponse` (answer deltas, then a final JSON line with
   citations + coverage + trace ids); a non-streaming variant returns one object.
3. `compendium/__main__.py`: `compendium serve [--host 127.0.0.1] [--port 8787]` runs uvicorn
   programmatically (lazy import of fastapi/uvicorn in the handler).
4. Default bind loopback-only; no auth; `--host` override documented as a v0.3 concern.
5. HTTP tests via FastAPI `TestClient` (integration, skip when stores down): each verb;
   `ask` covered/uncovered; bytes `ingest` immediately queryable; loopback-bind assertion.

**Files added:** `compendium/api/http.py`, `tests/test_http_api.py`
**Files modified:** `compendium/__main__.py`, `pyproject.toml` (fastapi, uvicorn)

**Decision flagged:** FastAPI + uvicorn per ADR-011; chunked-transfer streaming shape.

### 7c — MCP transport (`compendium mcp`)

**Purpose:** the six verbs as MCP stdio tools with schemas matching the facade shapes.

**Tasks:**

1. `compendium/api/mcp.py`: an MCP stdio server (official `mcp` SDK) registering the six verbs
   as tools; input schemas from the facade signatures; outputs are shared-serialized results.
2. `ask` streams via the SDK's progressive content, ending with the structured result.
3. `compendium/__main__.py`: `compendium mcp` runs the stdio server (lazy SDK import).
4. MCP tests via an in-process client (SDK memory streams) or direct tool-handler invocation:
   `list_tools` returns the six verbs with schemas; `query`/`ask` round-trip.

**Files added:** `compendium/api/mcp.py`, `tests/test_mcp_api.py`
**Files modified:** `compendium/__main__.py`, `pyproject.toml` (mcp)

**Decision flagged:** official MCP SDK, stdio only in v0.2.

## Out of scope for Phase 7 (do NOT build)

- Auth, TLS, and network-exposed transports (MCP-SSE, HTTP over LAN/Tailscale) — v0.3+ (ADR-011).
- gRPC — deferred (ADR-011).
- Curator/ops verbs over the surface (`curate`, `trace`, `page promote`, `reindex`,
  `graph link/rebuild`, `synth`) — CLI-only (ADR-011).
- A `compendium serve` launchd/systemd service unit and absorbing the Phase 3 schedule into
  the access-surface daemon — a later refactor (ADR-012).
- A web UI; multi-project namespacing / multi-tenancy.

## Open questions to confirm before starting

1. **HTTP framework.** Recommendation: FastAPI + uvicorn (ADR-011 names FastAPI). Alternative:
   stdlib `http.server` (no dependency, more handwritten code, weaker streaming).
2. **MCP SDK.** Recommendation: the official `mcp` Python package over stdio.
3. **Facade module path.** Recommendation: `compendium/api/` (`facade.py`, `http.py`,
   `mcp.py`, `serialize.py`). The build plan says "`compendium/api/facade.py` or similar".
4. **Default HTTP port.** Recommendation: `127.0.0.1:8787` (collision-free against the dev
   store ports).
5. **`ask` HTTP streaming shape.** Recommendation: chunked transfer — answer deltas, then a
   final JSON line with citations + coverage + trace ids. Alternative: Server-Sent Events.
6. **Serializer location.** Recommendation: one shared dataclass→dict helper that the
   transports and `--format json` all call, so the JSON contract lives in one place.
