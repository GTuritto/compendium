## Goal

Make curation autonomy configurable — manual, semi-auto (default), or auto —
governing concept synthesis and promotion, so the curator can let the machine do
the drafting while keeping (in manual/semi-auto) approval of what becomes
canonical.

## Why this plan exists

It locks in the central reconciliation: semi-auto preserves the load-bearing
half of the founding invariant (nothing canonical without curator approval) by
default, manual is the original behaviour as a mode, and only the opt-in auto
mode reverses the "SYNTHESIZES excluded forever" line. It also fixes the scope
(concept synthesis/promotion only) and the guardrails. Without it, "autocuration"
collapses into either no change or an unguarded reversal of the project's
identity.

### Na — mode + marker

**Purpose:** the setting and a way to mark machine output.

**Tasks:**

1. `manual | semi-auto | auto` setting (default `semi-auto`) in config.
2. The auto-generated/unreviewed marker for machine output: reuse
   `generator='synth'` + `status='draft'` if sufficient, else a small migration
   (decided per the open question).
3. ADR-022 inline in `docs/Compendium.md`.

**Files modified:** config; `docs/Compendium.md`; possibly a migration.

**Decision flagged:** reuse existing generator/status vs new marker (open q 1).

### Nb — semi-auto (default)

**Purpose:** propose-then-commit synthesis.

**Tasks:**

1. Autocurator drafts concept/merge/promotion proposals into the curation queue.
2. Curator approve / reject / edit before commit; nothing canonical without it.
3. Stub synthesizer for the hermetic tier; tests asserting no auto-commit.

**Files modified:** `compendium/curate/...`, the curation queue model, `__main__.py`

**Decision flagged:** proposals reuse the existing curation queue (unified inbox).

### Nc — auto (opt-in)

**Purpose:** the autonomous mode, fenced.

**Tasks:**

2. Guardrails: never overwrite curator pages, rate limit, provenance + revision
   + trace, reversible; tests.

**Files modified:** `compendium/curate/...`

**Decision flagged:** auto stays opt-in/off by default; shadow before live.

## Out of scope (do NOT build)

- Changing autonomous edge extraction (ADR-010) or CONTRADICTS (ADR-014).
- Making auto the default (it is opt-in, off, forever unless re-decided).
- Agent-triggered curation via the access surface (agent-write; backlog item 1).

## Open questions to confirm before starting

1. Machine-output marker: reuse `generator='synth'`+`status='draft'`, or add a
   dedicated value? Recommendation: reuse if it cleanly distinguishes
   machine-unreviewed from human drafts; otherwise a small enum addition.
2. Knob granularity: global, or per-operation (synth vs promote vs merge)?
   Recommendation: global first; add per-operation only if needed.
3. Where the setting lives: config file vs per-run flag. Recommendation: config
   default with a per-run override flag.
