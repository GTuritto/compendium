# Phase Plan — v0.3 Phase 1: Autonomous CONTRADICTS (curator-approved suggestions)

Plan of record: [docs/COMPENDIUM_V0.3_BUILD.md](../docs/COMPENDIUM_V0.3_BUILD.md) Phase 1
· OpenSpec: `openspec/changes/v0.3-phase-1-contradicts/` · Branch: `v0.3-phase-1-contradicts`
· Ships **ADR-014** · Version on completion: **0.2.4**

## Goal (verbatim from the build plan)

The slow loop autonomously *proposes* `CONTRADICTS` edges as curation signals;
the curator approves or drops each; an approved candidate becomes a
curator-owned `CONTRADICTS` edge in Memgraph. The LLM never writes a
`CONTRADICTS` edge directly.

## Open questions resolved

- **Q1 — signal kind:** add the distinct `contradiction_candidate` value
  (migration `0014`), per the plan's leaning: a proposed contradiction must
  never be confused with a curator-noticed `unresolved_contradiction`.
- **Q2 — resolve generality:** `curate resolve <id> --approve|--drop` is
  **generic** — drop works for every kind; approve dispatches through a
  per-kind action map whose first entry is `contradiction_candidate`. Other
  kinds answer with a clear error naming `curate synth` as their path.

## Sub-phases

- **1a — plumbing:** migration `0014` (ALTER TYPE ... ADD VALUE, no-op
  downgrade documented); `curation.contradict` settings block
  (`enabled`, `min_confidence: 0.7`, `top_k_neighbours: 10`,
  `full_sweep_every: 24`) + `config_sections.contradict()`; repository:
  `latest_signal_created_at(kind)`, `signal_pair_slugs(kind)`,
  (signals insert/status reuse the existing functions).
- **1b — the generator:** `curate/contradict.py`: `ContradictionLabel`
  (entity_id, confidence, rationale), `Contradictor` protocol,
  `StubContradictor` (first neighbour, 0.9, fixed rationale),
  `LLMContradictor` over the chat envelope, prompt id `contradict-v1`,
  `_parse_labels` (JSON array, fence-tolerant, mirrors extract);
  `from_contradiction_candidates(conn, driver, qclient, cfg)` with the
  signal-derived watermark, concept-pages-only sweep,
  `extract.nearest_neighbours` reuse, any-edge pre-filter
  (`schema.structural_pairs` ∪ new `schema.semantic_adjacent_ids`) and
  already-proposed pre-filter; structlog per proposal; `ContradictReport`
  counts into `CurateReport.contradictions` + the `graph_analysis_runs`
  summary. `model_clients` gains the fifth role `contradictor`
  (same `COMPENDIUM_SYNTH_STUB` + umbrella flags).
- **1c — resolve:** `curate/resolve.py` (`resolve(signal_id, approve)`),
  CLI `curate resolve <signal_id> --approve|--drop` + renderer, TUI curation
  screen `a`/`x` bindings over a `tui/data.py` provider function.
- **1d — tests** (`tests/test_contradict.py`, reusing the `extract_corpus`
  fixture): stub determinism; end-to-end candidate (signal exists, payload
  complete, `CONTRADICTS: 0`); approve (edge `extracted_by="curator"`,
  survives `graph rebuild`, signal `addressed`); drop; re-run proposes nothing
  (already-proposed + already-linked filters); resolve errors (unknown id,
  approve on a non-contradiction kind, already-resolved signal).
- **1e — docs:** ADR-014 inline in `docs/Compendium.md`; DECISIONS.md (new
  block + the section-7 deferral line now points at ADR-014); CLAUDE.md
  exclusion line updated; CONTEXT.md glossary (*Contradiction candidate*);
  `docs/operations/edge-extraction.md` extended; smoke section appended.
- **1f — completion:** `./release.sh 0.2.4` (VERSION + pyproject mirror +
  uv.lock + CHANGELOG section + `2Deploy/` rebuild) in the
  `v0.3 phase 1 complete` commit.

## Smoke test (appended to tests/manual/smoke_test.md)

Seed two contradicting concept pages; `curate run` → a
`contradiction_candidate` signal and **no** edge; `curate resolve <id>
--approve` → `CONTRADICTS: 1` with `extracted_by="curator"`; `curate run`
again → not re-proposed; `graph rebuild` → the edge survives (ADR-013).

## Acceptance gates

HEAD; the generator writes signals only (spec scenario); hermetic tier runs on
the stub contradictor; pipeline green on merge.
